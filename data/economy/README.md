# Faction economy building dataset

This dataset is the narrow standardized economy layer for the 104 playable faction keys in the Warhammer III 8.1.1 source snapshot. Each faction CSV catalogs its constructible building levels and only the ordinary economic facts that remain semantically comparable across factions.

- Game patch: 8.1.1 (Steam build 24237342)
- Playable faction files: 104
- Building rows: 24108
- Layout: `factions/<race>/<faction_key>.csv`

## Deliberately narrow scope

The CSVs contain applicable enabled culture/faction variants with base construction cost and duration, source level and settlement-tier requirement, simple prerequisites, and a small set of unconditional standardized outputs: fixed income, growth, control, single-resource trade output, and broad recruitment/upkeep modifiers.

They intentionally do not flatten conditional effects, percentage-income interactions, multi-resource landmarks, pooled-resource transactions, campaign scripts, or bespoke faction mechanics. Those belong in faction Markdown files where their exact numeric rules can be documented without pretending they share a universal column meaning. Blank means not applicable or not safely standardizable; zero means an observed zero.

## Machine-readable companions

- `faction_index__wh3__8.1.1.csv`: one row per playable faction file with counts, paths, hashes, and byte sizes.
- `schema_inventory__v1.csv`: ordered column definitions.
- `dataset_manifest.json`: patch, totals, race coverage, and explicit omissions.
- `audit_report.json` and `audit_report.md`: generated by the validator.

## Reproduction

With `rpfm_server.exe` running locally:

```powershell
node .\scripts\extract-economy-source.mjs data\economy\source_exports
node .\scripts\build-economy-dataset.mjs data\economy\source_exports work\generated_economy__final
node .\scripts\validate-economy-dataset.mjs data\economy\source_exports work\generated_economy__final
```
